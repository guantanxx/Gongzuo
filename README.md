# 创作舱 · 自媒体工作台

使用 HTML、CSS、原生 JavaScript 构建的独立静态网页，无第三方框架、字体、服务、后端或数据库。

## 当前进度：第一步

- 工作台概览与七个功能区导航：爆款拆解、灵感库、选题库、文案生成、直播中心、数据复盘、个人中心。
- 适配手机与电脑的响应式界面。
- 深色 / 浅色主题切换并本地保存。
- 创作者 IP 名称、内容领域、表达风格自动保存，刷新后恢复。
- 保存、主题切换与存储异常的即时提示。
- 键盘焦点、跳过导航链接与状态播报。

爆款拆解、灵感、选题、文案、直播和数据复盘目前为页面占位，尚未实现生成、数据记录、版本管理和图表。数据备份 / 恢复与风格自动迭代也将在后续步骤开发。概览中的零值表示尚无内容数据。

纯静态离线应用无法仅凭抖音 / 小红书链接自动抓取平台内容，也无法调用远程 AI。后续拆解与生成应基于用户补充的文本、创作者档案和本地规则实现，并明确其能力边界。

## 使用

直接打开根目录 `index.html` 即可使用，无需安装依赖或构建。也可在仓库目录运行 `python3 -m http.server 8000`，通过本地 HTTP 服务访问。

点击左侧导航（手机上为横向导航）切换页面，在个人中心填写创作者档案，右上角切换主题。数据保存在当前浏览器当前来源的 `localStorage`，键名为 `gongzuo.workspace.v1`。更换设备、域名、协议或清除网站数据不会保留原有记录；直接打开文件时，本地存储行为由浏览器决定，建议通过 HTTP 或 GitHub Pages 使用。请勿在档案中填写敏感信息。

## 文件

- `index.html`：静态入口、导航容器和布局。
- `styles.css`：响应式布局、组件与主题。
- `app.js`：页面渲染、导航、本地设置和即时反馈。

## 部署到 GitHub Pages

1. 将这些文件提交并推送到 GitHub 的 `main` 分支，确保 `index.html` 位于仓库根目录。
2. 打开仓库 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**。
4. 选择 **main** 分支和 **/ (root)**，点击 **Save**。
5. 等待 GitHub 部署成功，访问 Pages 面板显示的网址（通常为 `https://guantanxx.github.io/Gongzuo/`）。

所有资源使用相对路径，可部署到仓库子路径；无需配置密钥、环境变量或构建服务。
